# /prototype

Собери кликабельный прототип по пайплайну из скилла `clickable-prototype`.

Вход: `$ARGUMENTS` — короткое описание задачи, либо путь к папке с исследованием,
транскриптом встречи или документом с болями.

Прочитай скилл `clickable-prototype` и веди человека по его этапам, останавливаясь
на согласование там, где скилл этого требует. Если аргумент пустой — начни с
вопроса, для кого и зачем нужен прототип.
